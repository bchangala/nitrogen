Citing NITROGEN
===============

.. toctree::
   :maxdepth: 2
   

Please cite the specific version of the NITROGEN package used in published
work, including the persistent DOI. An example is below:
    
..  code-block::
    
    P. Bryan Changala, NITROGEN, version 2.1.2, https://github.com/bchangala/nitrogen 
    (https://doi.org/10.5281/zenodo.7342277)
